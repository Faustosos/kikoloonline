# Kikolo Online - Plano do Site

### 1. Páginas do Site
* **Página Inicial**: Vitrine com fotos e preços dos produtos.
* **Detalhes do Produto**: Página para ver tamanhos, cores e descrição.
* **Carrinho**: Lista dos produtos escolhidos e cálculo do total.
* **Finalizar Compra**: Formulário para entrega e dados de pagamento.

### 2. O que o cliente pode fazer
* Navegar pelos produtos físicos e digitais.
* Adicionar itens ao carrinho de compras.
* Fazer o pedido de forma rápida.
